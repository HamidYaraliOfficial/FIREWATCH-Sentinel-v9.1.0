# Security Testing References

FIREWATCH v3 maps its rule families conceptually to these public resources:

- [OWASP Top 10:2025](https://top10.owasp.org/2025/)
- [OWASP Web Security Testing Guide — stable](https://owasp.github.io/www-project-web-security-testing-guide/stable/)
- [OWASP API Security Top 10:2023](https://api-security.owasp.org/editions/2023/en/0x11-t10/)
- [OWASP ASVS releases](https://github.com/OWASP/ASVS/releases)
- [OWASP ZAP Automation Framework](https://www.zaproxy.org/docs/automate/automation-framework/)

A framework reference on a finding is guidance, not a claim that the framework's complete test case was performed or passed.
